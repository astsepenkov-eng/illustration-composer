# Конструктор иллюстраций

Локальный плагин Figma для сборки композиций из исходной векторной библиотеки. Для выполнения запросов используются локальные правила и смысловые теги. Плагин работает без сервера и API-ключей.

## Запуск

1. Откройте предоставленный рабочий файл в настольной Figma. В нём должна быть страница «Библиотека компонентов» с секциями «Размер L» и «Размер S», подписанными «Главные объекты» и «Фоновые объекты».
2. Откройте меню **Plugins → Development → Import plugin from manifest…** и выберите `manifest.json` из этой папки. Если в вашей установке импорт требует ID, создайте локальный плагин с интерфейсом через **Plugins → Development → New plugin**, затем возьмите его ID из сгенерированного манифеста и подставьте вместо текущего.
3. Запустите **Plugins → Development → Конструктор иллюстраций**. Результат добавляется на текущую страницу. Удобно запускать с отдельной страницы для композиций.
4. Для подготовки к сдаче откройте «Библиотека и импорт палитры» и нажмите «Собрать три примера». Для каждого выделите один фрейм, нажмите «Подготовить SVG» и скачайте файл.

## Короткая демонстрация

1. Введите «Книга, телефон», выберите L и горизонтальный формат. В списке ролей оставьте книгу главной, сделайте телефон фоновым и соберите композицию.
2. Выделите телефон и нажмите «Сменить роль предмета». Переместите или поверните объект в Figma.
3. Загрузите `palette-example.json` и нажмите «Применить палитру». Покажите изменение целой композиции.
4. Скачайте SVG и импортируйте его в Figma на отдельную страницу. Проверьте выделение и редактирование каждого объекта.
5. Переключитесь на подбор по заголовку, введите «Идеи всегда на связи» и соберите ещё одну композицию, выбрав S и другой формат.

## Как устроена библиотека

Исходные векторы хранятся в Figma. Код строит каталог ссылок на группы по предмету, размеру и роли. Роль определяется положением относительно подписей секции. Для безымянных групп учитываются названия вложенных слоёв и однозначное совпадение размеров с противоположной ролью. Неоднозначные группы и отсутствующие пары видны в отчёте. Результат содержит копии исходных групп, включая внутренние векторы. Единый коэффициент масштабирования сохраняет взаимный масштаб всех предметов. Ручное редактирование выполняется на холсте Figma.

При смене палитры плагин пересоздаёт копии из исходников, чтобы повторная перекраска давала тот же результат. Сохраняются положение, поворот, масштаб, прозрачность, видимость и порядок групп. При смене роли группа перемещается в соответствующую часть порядка слоёв. SVG экспортируется через Figma с идентификаторами слоёв. Плагин проверяет, что в выдаче нет растровых элементов.

Плагин читает три цветовые схемы из подписанных образцов в библиотеке. Если образцы не распознаны, отчёт показывает предупреждение и доступны резервные схемы. Импорт палитры принимает JSON с полями `name`, `canvas`, `background` и `objects`. В двух массивах ожидаются по четыре HEX-цвета, в том же порядке, что в колонках образцов сверху вниз. Фоновые предметы используют оттенки из `background`. Главные предметы используют обе группы оттенков, базовый чёрный и белый сохраняются.

Раскладка идёт по высоте в вертикальном формате и по ширине в горизонтальном. В квадрате с тремя и более предметами крупный главный объект получает отдельный ряд. Новые фреймы размещаются с отступом от объектов, которые уже находятся на странице.

Подбор по смыслу работает на локальном словаре тем и допускает незнакомые формулировки, если в них есть знакомые смысловые признаки. Если подходящих предметов нет, плагин просит уточнить запрос.

## Проверки

```powershell
node --test
```

Локальные проверки используют имитацию дерева слоёв. Для проверки самого плагина выполните демонстрационный сценарий в настольной Figma на исходной библиотеке.

## AI-инструменты

OpenAI Codex использован для анализа задания, проектирования, написания кода и локальных проверок. Во время работы плагина AI-сервис не вызывается.
